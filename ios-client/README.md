# Kiwi VPN for iPhone

Native Swift and SwiftUI, with a Packet Tunnel Provider extension using the official WireGuardKit, and the same Price Chat backend as Windows and Android. Version `0.1.0`, iOS 17 or later. **No part of it has been compiled yet, no IPA exists, and nothing has run on an iPhone.** Windows can't compile Swift for iOS.

## Layout
| Folder | What it is |
|---|---|
| `Packages/KiwiCore` | All logic: API, sign-in, device registration, connection states, rules. No UI, so `swift test` runs it on any Mac |
| `KiwiVPN` | The app: SwiftUI, sign-in sheet, VPN configuration, Shortcuts |
| `KiwiTunnel` | The Packet Tunnel extension: runs WireGuard, in its own process |
| `KiwiVPN.xcodeproj` | Generated by `tools/generate_xcodeproj.py`. `project.yml` is the fallback |
| `Vendor/wireguard-apple` | Official WireGuardKit source with two small build fixes: see its `KIWI-PATCHES.md` |

## What you need
- A Mac with **Xcode 16 or later**, and `brew install go`, because WireGuardKit compiles Go.
- A real iPhone on iOS 17 or later. **The Simulator can't run a Network Extension.**
- A **paid Apple Developer account**. Testing needs only that. **The App Store needs one enrolled as an organization:** see `docs/APPLE-CHECKLIST.md`.

## Build on a Mac
1. **On Windows,** make the package:
   ```powershell
   powershell -ExecutionPolicy Bypass -File ios-client\prepare-mac-package.ps1
   ```
2. **On the Mac,** unzip it, then run the logic tests. These need no account:
   ```bash
   cd kiwi-ios-source
   chmod +x tools/build-mac.sh
   ./tools/build-mac.sh
   ```
3. **Sign and build.** In Xcode: open `KiwiVPN.xcodeproj`, and wait for packages to resolve. For both `KiwiVPN` and `KiwiTunnel`, go to Signing & Capabilities and choose your Team. Or from the terminal:
   ```bash
   ./tools/build-mac.sh YOURTEAMID
   ```
4. **Run:** connect the iPhone, select it as the destination, and press Run. Turn on Developer Mode on the iPhone if asked. Then follow `docs/IPHONE-TEST-PLAN.md`.

**If Xcode rejects the project,** run `brew install xcodegen && xcodegen generate`. Expect the first compile to report some errors, since none of this has met a compiler. Send them to me and I'll fix them.

**If the Go bridge fails with `make` errors,** check `go version`, then in Xcode choose File > Packages > Reset Package Caches.
