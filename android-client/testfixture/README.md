# Stand-in call apps

Tiny test apps that use WhatsApp's and Telegram's package names, so the Android 16 emulator delivers real notifications to Auto-Call VPN's listener. They contain no code from either app, and make no calls.

**They show what Kiwi VPN does with a notification of a given shape. They can't show what WhatsApp or Telegram really send.** Only a real call on a real phone can, using the list in Settings > Connection diagnostics > What Auto-Call VPN saw.

**Emulator only, and never publish them.** Installing one blocks the real app of that name.
